# Miniros v2 implementation plans

Start with [START_HERE_CODEX.md](START_HERE_CODEX.md), then read the [master plan](MASTER_PLAN.md).

This is the split repository edition of the complete implementation plan supplied on 7 September 2026. It contains all 20 execution plans, EP00 through EP19, their validation tests, agent instructions, requirements, tracking templates, and synthetic fixtures. The duplicate combined Markdown edition is intentionally omitted so the split documents remain the active source.

`FILE_MANIFEST.json` lists SHA-256 hashes of the other files in this directory; the manifest excludes itself to avoid a circular checksum.
