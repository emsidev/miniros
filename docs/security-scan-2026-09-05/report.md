## Threat Model

MINIROS is a multi-business retail operations web/PWA: browser inputs enter Next App Router Server Actions or offline Route Handlers, use server authorization and shared contracts/domain code, then commit Drizzle transactions to Supabase Postgres; Supabase supplies Auth, Storage and Realtime. Owners/admins manage shifts/configuration/recovery and employees operate assigned shifts/POS/production. Production root start launches @miniros/web next start; package build additionally emits PWA assets. Astro marketing is separate; API workflow-preview and agent/mobile shells are supporting scaffolds, not the new offline authority path. This architecture review covers the current source state and supporting controls, not completed vulnerability coverage. Sources: README.md:3-20; docs/architecture.md:9-26; package.json:7-16; apps/web/package.json:5-8; apps/api/src/server.ts:12-59.
